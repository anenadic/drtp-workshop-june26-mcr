# dRTP workshop skills activity

Analyse the results of the data role skills activity [(survey)](https://forms.gle/Y1WoU1L2DWyLm4cR8). Part of the [dRTP workshop 2 UoM](https://www.eventbrite.co.uk/e/uom-drtp-workshop-2-support-for-data-stewards-and-recognition-for-all-rtps-tickets-1986157123422).

## Run

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 skills-roles-analysis.py
```
